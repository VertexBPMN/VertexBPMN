# VertexBPMN Wiki

VertexBPMN ist eine .NET-Engine für BPMN 2.0, CMMN 1.1 und DMN 1.4.

## Einstieg

- [Getting Started](Getting-Started) - API lokal starten und ersten Prozess deployen
- [BPMN ausführen](BPMN-ausführen) - Instanzen, Variablen und User-Tasks
- [REST API](REST-API) - wichtige Endpunkte und curl-Beispiele
- [.NET SDK](SDK-Dotnet) - NuGet-Paket `VertexBPMN.Sdk`
- [Tipps und Tricks](Tipps-und-Tricks)
- [Troubleshooting](Troubleshooting)

## Welche Variante passt?

| Ziel | Einstieg |
| --- | --- |
| Engine in einer .NET-Anwendung einbetten | Application-/Engine-Projekte |
| Remote-Engine aus .NET nutzen | `VertexBPMN.Sdk` |
| JavaScript, Python oder Java verwenden | REST/OpenAPI |
| Modelle grafisch bearbeiten | VertexBPMN Studio und bpmn.io |

Die Beispiele beziehen sich auf die aktuelle API im Repository. OpenAPI und SDK sollten aus demselben Release stammen.
