# VertexBPMN Dokumentation

Dies ist der Einstiegspunkt fuer die Dokumentation.

Die Inhalte sind jetzt nach ihrem Zweck getrennt:

- `getting-started/` fuer den schnellen Einstieg
- `guide/` fuer praktische Arbeitsablaeufe
- `reference/` fuer API-, SDK- und Modellreferenzen
- `architecture/` fuer technische Konzepte und Entscheidungen
- `runbooks/` fuer Betrieb, Release und Troubleshooting
- `working/` fuer laufende Plaene und Feature-Matrizen
- `archive/` fuer historische, aber noch nachvollziehbare Dokumente
- `assets/` fuer PDFs, Bilder und andere Begleitdateien
